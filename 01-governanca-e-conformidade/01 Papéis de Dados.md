# 👥 Papéis na gestão de dados

Quem faz o quê quando uma organização coleta, guarda e trata dados.

| Papel | Responsabilidade principal |
|---|---|
| **Proprietário de dados** | É o responsável pelos dados. Define o que é ou não permitido de acordo com as políticas. |
| **Controlador de dados** | Decide o que será feito com os dados e quais dados precisam ser coletados. |
| **Processador / Operador de dados** | Executa o tratamento dos dados conforme as instruções do controlador. Define também *onde* os dados ficam. |
| **Custodiante de dados** | Garante a segurança técnica: monitoramento, criptografia e proteção dos dados coletados e armazenados. |
| **Administrador de dados** | Mantém tudo organizado conforme as políticas e as necessidades da empresa, inclusive para gerar relatórios. |
| **Oficial de Proteção de Dados (DPO)** | Supervisiona a estratégia de proteção e a conformidade legal. Orienta a equipe para que tudo fique dentro das normas. |
